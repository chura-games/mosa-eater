# ABYSSAL APEX：最深水域の覇者
Three.js + TypeScript の3Dブラウザゲームの小さなプロトタイプ。

**▶ ゲームを開く：[https://chura-games.github.io/mosa-eater/](https://chura-games.github.io/mosa-eater/)**

開発中の手元の版は [http://127.0.0.1:5173](http://127.0.0.1:5173)（開発サーバー起動中のみ。自分のPC専用）。

## 公開（GitHub Pages）
main へプッシュすると `.github/workflows/pages.yml` がビルドして `dist/` を GitHub Pages に公開する。初回だけ、リポジトリの Settings → Pages → Source を「GitHub Actions」にする。`vite.config.ts` で相対パスにしているので、`/mosa-eater/` の下でも動く。

## 起動
Node.js 22推奨。初回は npm install、その後 npm run dev。
起動したら [http://127.0.0.1:5173](http://127.0.0.1:5173) をPCブラウザーで開く。
npm run build で型チェックと本番ビルド。npm run preview でビルドを確認。

## 操作
- タイトル画面でWを押すとそのまま開始して前進する。開始ボタンも使用できる。停止中は尾の泳ぎを止め、移動入力で泳ぎを開始する。
- マウス：左右・上下の視点。マウスだけでは体は回らない。W：前進しながら視線方向にゆっくり向き直る。S：体の向きに対して後退。A / D：カメラ基準の左右移動。上・下を向いてWで泳ぐと体も徐々に傾いて浮上・潜水する。
- Q / R：潜水 / 浮上
- Shift + W：ブースト
- ジャンプ：上を向いたまま W で水面へ突っ込むと、その勢いで空中へ跳び出す。速いほど高く跳ぶ（ブーストで最大）。ゆっくり浮上したときは水面で止まる。
- 上陸：浜へ向かってそのまま進むと砂浜へ這い上がれる。陸上では動きが遅くなる。
- 口元の獲物に自動で噛みつく。Space / 海の画面をクリックでも噛みつける。
- 体は食べた分だけ自動で大きくなる（100 BPごとに1段階、最大8段階）。
- Esc：一時停止とマウス解放。一時停止メニューで音量・画質（低/中/高）・影・流血表現（控えめ/標準/過激）を変更でき、設定は次回も引き継ぐ。SOUNDボタン：音のオン・オフ。

## ローディング画面
起動時は黒い画面の中央にスタジオロゴの動画（`src/assets/load/chura-games-logo.mp4`）を埋め込んで再生し、下に読み込みの進み具合を表示する。動画の外側は動画と同じ黒（#000）。モデルの読み込みと動画の再生が両方終わるとタイトルへ切り替わる。読み込み完了後はクリックかキー入力で動画の残りを飛ばせる。動画を再生できない環境では読み込み完了と同時に切り替わる。

## 実装範囲
三人称カメラ、GLBモデルのモササウルスと尾・顎アニメーション、海面・海底・ビーチ・海上施設、逃走AI、捕食判定、BPと体長の自動成長（最大8段階）、恐怖度と迎撃艇、合成した効果音、流血・破壊表現とカメラ振動。
プレイヤーは無敵。迎撃艇はブーストを消耗させる。獲物は18秒で再出現。10匹捕食で最初の目標達成、その後も遊べる。
形状を作り込んだスタイライズ表現で、外部の3Dモデル・画像・音源は使わない。マップは幅720mの連続した海岸で、浅瀬から砂浜・砂丘へ続く。砂浜にはヤシ、パラソル、デッキチェアを配置する。

## 3Dモデル
全オブジェクトの形状とマテリアルは `src/assets/` のGLBに保存し、GLTFLoaderで起動時に読み込む。Blenderなどで開いて編集できる。ダイバーの潜水装備、サメのえら、船の手すり・船外機、ヤシの羽状の葉、パラソルの骨組み、海上施設の配管・クレーンまで個別に造形している。ファイル一覧は `src/assets/README.md` を参照。
全アセットの読み込み完了まで開始ボタンは待機する。読み込み失敗時はエラーを表示する。モデルを一度読み込み、獲物やエフェクトは複製して使う。
モササウルスは滑らかな断面で作った胴体と長い吻、薄く先細りのヒレ、非対称の尾びれ、上下の顎、眼と歯を持つ。GLB内の頂点カラーで背中の暗色と腹側の明色、斑模様を表現する。泳ぎに合わせて尾とヒレを動かし、旋回中は体が傾く。
尾の `Tail` と顎の `Jaw` は回転用の親ノード。編集・差し替え時も名前と回転の支点を維持する。前方は-Z、上方向は+Y、モデル原点は胴体中央。基準サイズと口の位置を変える場合はMosasaurus.tsの捕食判定も合わせる。
`npm run assets:generate` で全GLBを再生成できる（編集済みモデルを上書きするため注意）。通常の起動・ビルドでは再生成しない。海面の波、尾・顎の動き、捕食粒子、ソナーなどのアニメーションは読み込んだ形状に対してコードで行う。砂浜と海のマップは maps/coast.glb、個別オブジェクトは objects/、エフェクトは effects/ に分離。環境オブジェクトの配置は maps/coast.layout.json を編集する。
海岸線と傾斜の設定は `src/assets/maps/coast.profile.json` で共有し、モデル生成・浅瀬の水面描画・獲物の出現位置を合わせる。設定変更後はモデルを再生成する。

## 生き物と乗り物
獲物は ダイバー、遊泳者、砂浜を歩く観光客、サーファー、サメ、魚の群れ、マグロ、ウミガメ、イルカ、シャチ、アザラシ、エイ、クラゲ、小型船、水上バイク、カヤック、ヨット、ブイ、迎撃艇。マグロは魚、シャチはイルカのモデルを拡大・着色して使う。カモメと海藻は景色で、捕食できない。種類ごとの速さ・旋回の速さ・得点・耐久は `src/entities/Human.ts` の表で決める。
どれも旋回の速さに上限があり、速度はなめらかに変化する。魚とサメは尾を振って進み、旋回で体を傾ける。イルカは尾を上下に打ち、ときどき水面から跳ねる。ウミガメは前びれを羽ばたかせ、ダイバーと遊泳者は足を交互に蹴る。魚は先頭の1匹の横の定位置を保って群れる。船・水上バイク・ブイは描画と同じ波の高さと傾きに乗り、加速で船首が上がり、旋回で傾く。地形に当たると沖へ向き直る。
モササウルスは加速が速く、入力を離すとしばらく滑って進む。尾の振りに合わせて胴がしなり、旋回方向へ体を曲げる。ヤシの葉・草・海藻は揺れ、泡は海底から水面へ上る。

## 捕食の動きと破壊表現
噛みつきは、体を前へ突き出して大きく口を開け、開くより速く閉じる。小さな獲物は血煙とともに丸呑みする。大きな獲物は顎に咥えたまま頭を左右に振り回し、振るたびに血が噴き出す。最後は体が肉片に裂けて飛び散り、骨と肉のかけらが血の尾を引いて沈み、海面に血の膜が広がって波に乗る。捕食後しばらくは歯が血で染まり、画面の縁が赤く光る。シャチは2回噛まないと仕留められず、1回目で傷を負って逃げる。水上バイクとカヤックは乗り手ごと壊れる。流血の量は一時停止メニューの「流血表現」で変えられる。
生き物を捕食すると、暗い血の煙が傷口から広がって水中に漂い、薄れていく。船やブイなどの物体は、モデルの形状を位置ごとの破片に分けて吹き飛ばす。破片は空中では落下し、水中では減速して、浮くものと沈むものに分かれる。船に噛みついて壊しきれなかったときは、当たった場所の破片だけが飛ぶ。水しぶきと煙も出る。画像ファイルは使わず、すべてコードで生成する（`src/system/Effects.ts`）。

## 上陸・ジャンプ・水面
泳ぐ深さより上に出た体には重力がかかる。空中では放物線を描いて落ち、砂浜では地面に支えられて這う。砂浜の観光客は海から何かが上がってくると走って逃げる。陸上で捕食すると血は煙にならず飛び散って落ち、砂に血だまりが残る。肉片や破片は砂や海底の上で止まる。
水面を突き破ったとき・落ちたとき・獲物が跳ねたとき・船が壊れたときは、その場所から波紋の輪が広がる。背中が水面近くにある間は、体の周りの水面が揺れ続ける（shaders/water.frag）。
レーダーとソナーは廃止した。画面右下には深度だけを表示する。

## 音
音はすべてWeb Audioで合成し、音声ファイルは使わない（`src/system/Sound.ts`）。海上の波音、水中の低いうなり、泳ぐ速さに応じた水流音、恐怖度に応じて強まる低音。顎を閉じる音、骨が砕けて肉が裂ける音、咥えて振るたびの音、飲み込む音、短い悲鳴、船体が壊れる音（鉄の船は金属の響き付き）、水しぶき、成長時の咆哮、迎撃艇の警報、カモメの声。カメラが水中にあるときは全体がこもって聞こえる。

## 接触と捕食
獲物が顎の前方に入ると自動で噛みつく。噛みつき間隔は0.55秒。顎の前方にある獲物だけが、噛みつき中の閉じるタイミングで捕食される。モデルの各パーツの回転と大きさを反映し、1回の噛みつきは1体に命中する。捕食可能な獲物に照準が合うと緑になる。岩や砂浜、施設越しには捕食できない。
船は小型船2回、迎撃艇3回の噛みつきで破壊。前方へのブースト体当たりは2ダメージ。触れ続けるだけでは連続ダメージにならない。
地形に当たったときは押し戻された向きを覚え、その面に沿って滑る。斜めに当たっても速度はほとんど落ちず、正面からぶつかったときだけ減速する。滑っている間は鼻先も面に沿って起きる。
胴体・頭・尾の複数の球で岩、砂浜、海底、施設のモデル表面に接触し、船はパーツ別の判定で接触する。泳ぎを小さな時間刻みに分けて高速時のすり抜けを防ぐ。体長の成長と旋回も判定に反映する。
生物と船は元の各パーツの境界ボックスによる近似。描画用にメッシュを結合しても、GLB内に保存したパーツの境界で判定する。プレイヤーの体は複数球による近似で、全頂点同士の物理シミュレーションではない。地形の接触判定は近くの三角形に絞って調べる。

## カメラと水面
マウス視点は時間に応じて補間する。カメラは、平滑化したプレイヤーの速度に対して一定時間ぶん後ろへ遅れる位置に置く。位置そのものを追いかける方式ではフレーム時間のばらつきが揺れとして見えるため使わない。カメラの更新はプレイヤーの移動後に行い、地形にめり込まないよう持ち上げる。捕食時の揺れは小さくし、追従位置にノイズを蓄積させない。衝突の安全な細かい刻みは維持し、獲物AIとHUDは必要な頻度で更新する。
水中のモデル表面には、assets/shaders/marine-light.fragで時間変化する網目状の光の揺らぎ（コースティクス）を加える。遠くでは細い線をならして、ちらつきを抑える。
プレイ範囲の外側には、遠景の丘と湾を囲む岬（maps/coast.glb の CoastalHills）を置く。接触判定は持たない。海底は浅瀬から沖へ滑らかに深くなる。
水中では空と水面の霞の色をシーンのフォグ色に合わせ、遠くの地形が輪郭を残さず霞む。
海面は maps/coast.glb の形状に assets/shaders/water.vert と water.frag を適用する。GPUで波と法線を計算し、大きなうねり・不規則な細波・視線角度に応じた空の色と太陽のハイライト・浅瀬と深海の色・透明度・波打ち際の泡・航跡を描く。船は同じ波の高さに追従する。水中への切り替えも水面の高さを使って滑らかに行う。水面上では周囲の景色を鏡面レンダリングで映し込み、水中からは空色の近似を使う。泡は重ねたノイズで不規則な筋にする。
