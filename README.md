# ABYSSAL APEX：最深水域の覇者
Three.js + TypeScript の3Dブラウザゲームの小さなプロトタイプ。

**▶ ゲームを開く：[https://chura-games.github.io/mosa-eater/](https://chura-games.github.io/mosa-eater/)**

開発中の手元の版は [http://127.0.0.1:5173](http://127.0.0.1:5173)（開発サーバー起動中のみ。自分のPC専用）。

## 公開（GitHub Pages）
main へプッシュすると `.github/workflows/pages.yml` がビルドして `dist/` を GitHub Pages に公開する。初回だけ、リポジトリの Settings → Pages → Source を「GitHub Actions」にする。`vite.config.ts` で相対パスにしているので、`/mosa-eater/` の下でも動く。

## 起動
Node.js 22推奨。初回は npm install、その後 npm run dev。
起動したら [http://127.0.0.1:5173](http://127.0.0.1:5173) をPCブラウザーで開く。
npm run build で型チェックと本番ビルド。npm run preview でビルドを確認。

## 操作
- 体長10cmの孵化直後から始まり、食べるほど大きくなる（最大60m）。口に入る大きさ（自分の体長の1.3倍まで）の相手だけ噛み砕ける。
- 画面上部にニュースが流れる。最初は日常のニュースで、捕食や成長に応じて速報に切り替わる。
- 体力（HEALTH）がある。小さいうちはバラクーダやサメ、大きくなるとシャチやメガロドン、ダイオウイカ、さらに迎撃艇・攻撃ヘリ・潜水艦・戦艦が攻撃してくる。体力が尽きると体が3割縮む。
- アドレスの末尾に `?size=12` のように付けると、その体長（m）から始められる（後半の確認用）。
- タイトル画面でWを押すとそのまま開始して前進する。開始ボタンも使用できる。停止中は尾の泳ぎを止め、移動入力で泳ぎを開始する。
- マウス：左右・上下の視点。マウスだけでは体は回らない。W：前進しながら視線方向にゆっくり向き直る。S：体の向きに対して後退。A / D：カメラ基準の左右移動。上・下を向いてWで泳ぐと体も徐々に傾いて浮上・潜水する。
- Q / R：潜水 / 浮上
- Shift + W：ブースト
- ジャンプ：上を向いたまま W で水面へ突っ込むと、その勢いで空中へ跳び出す。速いほど高く跳ぶ（ブーストで最大）。ゆっくり浮上したときは水面で止まる。
- 上陸：浜へ向かってそのまま進むと砂浜へ這い上がれる。陸上では動きが遅くなる。
- 口元の獲物に自動で噛みつく。Space / 海の画面をクリックでも噛みつける。
- 体は食べた分だけ自動で大きくなる（100 BPごとに1段階、最大8段階）。
- Esc：一時停止とマウス解放。一時停止メニューで音量・画質（低/中/高）・影・流血表現（控えめ/標準/過激）を変更でき、設定は次回も引き継ぐ。SOUNDボタン：音のオン・オフ。

## ローディング画面
起動時は黒い画面の中央にスタジオロゴの動画（`src/assets/load/chura-games-logo.mp4`）を埋め込んで再生し、下に読み込みの進み具合を表示する。動画の外側は動画と同じ黒（#000）。モデルの読み込みと動画の再生が両方終わるとタイトルへ切り替わる。読み込み完了後はクリックかキー入力で動画の残りを飛ばせる。動画を再生できない環境では読み込み完了と同時に切り替わる。

## 実装範囲
三人称カメラ、GLBモデルのモササウルスと背骨・顎アニメーション、海面・海底・ビーチ・海上施設、逃走AIと捕食者AI、捕食判定、体長10cm〜60mの連続的な成長、体力と敵の攻撃（噛みつき・機銃・砲弾・魚雷）、恐怖度、ニュース速報、合成した効果音、流血・破壊表現とカメラ振動。
プレイヤーは無敵。迎撃艇はブーストを消耗させる。獲物は18秒で再出現。10匹捕食で最初の目標達成、その後も遊べる。
形状を作り込んだスタイライズ表現で、外部の3Dモデル・画像・音源は使わない。マップは幅960mの連続した海岸で、浅瀬から砂浜・砂丘へ続く。砂浜にはヤシ、パラソル、デッキチェアを配置する。

## 3Dモデル
全オブジェクトの形状とマテリアルは `src/assets/` のGLBに保存し、GLTFLoaderで起動時に読み込む。Blenderなどで開いて編集できる。ダイバーの潜水装備、サメのえら、船の手すり・船外機、ヤシの羽状の葉、パラソルの骨組み、海上施設の配管・クレーンまで個別に造形している。ファイル一覧は `src/assets/README.md` を参照。
全アセットの読み込み完了まで開始ボタンは待機する。読み込み失敗時はエラーを表示する。モデルを一度読み込み、獲物やエフェクトは複製して使う。
モササウルスは滑らかな断面で作った胴体と長い吻、薄く先細りのヒレ、非対称の尾びれ、上下の顎、眼と歯を持つ。頭骨は唇の線で平らに切ってあり、その下に下顎がはまる。口の中には口蓋、舌、喉の奥、歯茎、上下で互い違いに噛み合う大小の反った歯、口蓋の小さな歯列がある。口を開けると下顎が下がると同時に頭骨が持ち上がり、下顎は左右に広がる。咀嚼では下顎を前後に動かして獲物を喉へ送る。GLB内の頂点カラーで背中の暗色と腹側の明色、斑模様を表現する。泳ぎに合わせて尾とヒレを動かし、旋回中は体が傾く。
胴体と尾びれは1枚の皮膚で、背骨の骨12本（`Spine` を中心に、前へ `Chest`・`Neck`・`Head`、後ろへ `Lumbar`・`Hip`・`Tail`〜`Tail6`）に沿って曲がる。顎の `Jaw`、眼、歯は `Head` に、前ヒレは `Chest`、後ろヒレは `Hip` に付く。編集・差し替え時も骨の名前と位置、`Jaw` の支点を維持する。前方は-Z、上方向は+Y、モデル原点は胴体中央。基準サイズと口の位置を変える場合はMosasaurus.tsの捕食判定も合わせる。
`npm run assets:generate` で全GLBを再生成できる（編集済みモデルを上書きするため注意）。通常の起動・ビルドでは再生成しない。海面の波、尾・顎の動き、捕食粒子、ソナーなどのアニメーションは読み込んだ形状に対してコードで行う。砂浜と海のマップは maps/coast.glb、個別オブジェクトは objects/、エフェクトは effects/ に分離。環境オブジェクトの配置は maps/coast.layout.json を編集する。
海岸線と傾斜の設定は `src/assets/maps/coast.profile.json` で共有し、モデル生成・浅瀬の水面描画・獲物の出現位置を合わせる。設定変更後はモデルを再生成する。

## 生き物と乗り物
獲物は小さい順に、オキアミ（2.5cm）、エビ、小魚の群れ、カニ（海底を歩く）、イワシの群れ、イカ、クラゲ、魚の群れ、バラクーダ、ダイバー、遊泳者、砂浜を歩く観光客、サーファー、マグロ、ウミガメ、アザラシ、アシカ、エイ、イルカ、サメ、シャチ、ダイオウイカ、クジラ、メガロドン。乗り物は カヤック、水上バイク、小型船、ヨット、ブイ、フェリー（48m）、迎撃艇、攻撃ヘリ、潜水艦（44m）、戦艦（72m）。オキアミはエビ、小魚・イワシ・バラクーダ・マグロは魚、アシカはアザラシ、メガロドンはサメ、ダイオウイカはイカのモデルを拡大縮小・着色して使う。
小さな獲物は、モササウルスがそれを相手にする大きさの間だけ現れる（体長50cmを超えるとオキアミは出なくなる、など）。海の生き物はモササウルスの周囲に現れ直すので、マップのどこにいても近くに獲物がいる。相手の体長が自分の1.3倍以下なら噛み砕ける。14%未満なら丸呑み、75%までは咥えて振り回し、それ以上はその場で引き裂く。食べた相手が大きいほど大きく育つ（1回の食事で最大3割）。

## 敵の攻撃
バラクーダ、サメ、シャチ、ダイオウイカ、メガロドンは、モササウルスが自分の体長の約3.5%〜70%の大きさのとき獲物として襲ってくる（10cmの孵化直後はバラクーダ、1m前後ではサメとシャチ、数mではダイオウイカとメガロドン）。突進して噛みつき、離れてからまた戻ってくる。8秒追って捕まえられなければ、しばらく諦める。狙われると画面に警告が出る。開始から25秒間と、倒された直後の7秒間は狙われない。
軍は体長に応じて出動する。4m（または恐怖度50%）で迎撃艇4隻、9mで攻撃ヘリ2機、16mで潜水艦2隻、26mで戦艦、30mでヘリ追加、42mで戦艦2隻目。迎撃艇とヘリは機銃、戦艦は砲弾、潜水艦は追尾する魚雷を撃つ。弾は撃った瞬間の位置を狙うので動けば外れる。機銃と砲弾は深く潜ると届かない。ヘリは低空に降りて撃つので、跳び上がれば噛み砕ける。体が大きいほど1発の被害は小さい。体力は4秒間攻撃を受けなければ回復し、食べても回復する。
シャチは白黒模様の専用モデル。クジラは体長約14mで、4回噛まないと仕留められず、ときどき水面に上がって潮を吹く。大きすぎて咥えられないので、その場で引き裂かれる。大型の獲物は沖の深い場所にいる。カモメと海藻は景色で、捕食できない。種類ごとの速さ・旋回の速さ・得点・耐久は `src/entities/Human.ts` の表で決める。
どれも旋回の速さに上限があり、速度はなめらかに変化する。魚とサメは尾を振って進み、旋回で体を傾ける。イルカは尾を上下に打ち、ときどき水面から跳ねる。ウミガメは前びれを羽ばたかせ、ダイバーと遊泳者は足を交互に蹴る。魚は先頭の1匹の横の定位置を保って群れる。船・水上バイク・ブイは描画と同じ波の高さと傾きに乗り、加速で船首が上がり、旋回で傾く。地形に当たると沖へ向き直る。
モササウルスは加速が速く、入力を離すとしばらく滑って進む。腰から尾の先へ波が順に伝わり、尾に近いほど大きく振れる。首は逆向きに動いて頭を安定させる。旋回では首が先に向きを変え、体全体が弧を描く。上昇・下降では背骨が上下に反り、獲物を振り回すときは首を振って尾が逆へしなる。ヤシの葉・草・海藻は揺れ、泡は海底から水面へ上る。

## 捕食の動きと破壊表現
噛みつきは、体を前へ突き出して大きく口を開け、開くより速く閉じる。小さな獲物は血煙とともに丸呑みする。大きな獲物は顎に咥えたまま頭を左右に振り回し、振るたびに血が噴き出す。最後は体が肉片に裂けて飛び散り、骨と肉のかけらが血の尾を引いて沈み、海面に血の膜が広がって波に乗る。捕食後しばらくは歯が血で染まり、画面の縁が赤く光る。シャチは2回噛まないと仕留められず、1回目で傷を負って逃げる。水上バイクとカヤックは乗り手ごと壊れる。流血の量は一時停止メニューの「流血表現」で変えられる。
生き物を捕食すると、暗い血の煙が傷口から広がって水中に漂い、薄れていく。船やブイなどの物体は、モデルの形状を位置ごとの破片に分けて吹き飛ばす。破片は空中では落下し、水中では減速して、浮くものと沈むものに分かれる。船に噛みついて壊しきれなかったときは、当たった場所の破片だけが飛ぶ。水しぶきと煙も出る。画像ファイルは使わず、すべてコードで生成する（`src/system/Effects.ts`）。

## 上陸・ジャンプ・水面
泳ぐ深さより上に出た体には重力がかかる。空中では放物線を描いて落ち、砂浜では地面に支えられて這う。砂浜の観光客は海から何かが上がってくると走って逃げる。陸上で捕食すると血は煙にならず飛び散って落ち、砂に血だまりが残る。肉片や破片は砂や海底の上で止まる。
水面を突き破ったとき・落ちたとき・獲物が跳ねたとき・船が壊れたときは、その場所から波紋の輪が広がる。背中が水面近くにある間は、体の周りの水面が揺れ続ける（shaders/water.frag）。
レーダーとソナーは廃止した。画面右下には深度だけを表示する。

## マップの広さと軽量化
プレイ範囲は幅880m・沖へ約670m（`coast.profile.json` の playHalfWidth / playMaxZ）。岸から140m付近までは水深30mまでの棚で、その先は水深85mまで落ち込む（deepDepth / deepStart / deepEnd）。海上施設は3基。砂浜と海底の接触判定は三角形ではなく高さの式で行うので、マップを広げてもメモリを使わない。
見た目を変えない範囲で軽くしている。モデルは結合後に頂点を共有し直す（形と面数は同じまま、ファイルが小さくなる）。水面の映り込みは、カメラが水中にあって見えない間は描かない。影はプレイヤーの周囲だけを対象にする。背景物は70m四方の区画ごとにまとめ、画面外・影の範囲外・水中で霞に隠れる区画は描かない。水中で霞に完全に隠れる距離（体長12mで125m。体が大きいほど遠くまで見える）の獲物は描画しない。小さな獲物は、見分けがつかない距離（体長の260倍）より遠くでは描かない。今の体長では出番のない獲物と、出動前の軍は処理も描画もしない。地形との接触判定は獲物の半分ずつを交互に調べる。水中の光の模様は水面より上では計算しない。
画質「中」「低」を選んだときだけ、映り込みと影の更新を間引く。画質が自動で下がることはない。

## 音
音はすべてWeb Audioで合成し、音声ファイルは使わない（`src/system/Sound.ts`）。海上の波音、水中の低いうなり、泳ぐ速さに応じた水流音、恐怖度に応じて強まる低音。顎を閉じる音、骨が砕けて肉が裂ける音、咥えて振るたびの音、飲み込む音、船体が壊れる音（鉄の船は金属の響き付き）、水しぶき、成長時の咆哮、迎撃艇の警報、カモメの声。人は、モササウルスに気づいた瞬間に悲鳴を上げる（男女で声の高さが違い、近いほど大きい）。捕まると長い悲鳴が途中で途切れ、ごぼごぼという音に変わる。恐怖度が高い間は、遠くの浜から悲鳴が断続的に聞こえる。イルカとシャチは甲高い鳴き声、クジラは低いうめき、アザラシとアシカは吠え声を上げる。カメラが水中にあるときは全体がこもって聞こえる。

## 接触と捕食
獲物が顎の前方に入ると自動で噛みつく。噛みつき間隔は0.55秒。顎の前方にある獲物だけが、噛みつき中の閉じるタイミングで捕食される。モデルの各パーツの回転と大きさを反映し、1回の噛みつきは1体に命中する。捕食可能な獲物に照準が合うと緑になる。岩や砂浜、施設越しには捕食できない。
船は小型船2回、迎撃艇3回の噛みつきで破壊。前方へのブースト体当たりは2ダメージ。触れ続けるだけでは連続ダメージにならない。
地形に当たったときは押し戻された向きを覚え、その面に沿って滑る。斜めに当たっても速度はほとんど落ちず、正面からぶつかったときだけ減速する。滑っている間は鼻先も面に沿って起きる。
胴体・頭・尾の複数の球で岩、砂浜、海底、施設のモデル表面に接触し、船はパーツ別の判定で接触する。泳ぎを小さな時間刻みに分けて高速時のすり抜けを防ぐ。体長の成長と旋回も判定に反映する。
生物と船は元の各パーツの境界ボックスによる近似。描画用にメッシュを結合しても、GLB内に保存したパーツの境界で判定する。プレイヤーの体は複数球による近似で、全頂点同士の物理シミュレーションではない。地形の接触判定は近くの三角形に絞って調べる。

## カメラと水面
マウス視点は時間に応じて補間する。カメラは、平滑化したプレイヤーの速度に対して一定時間ぶん後ろへ遅れる位置に置く。位置そのものを追いかける方式ではフレーム時間のばらつきが揺れとして見えるため使わない。カメラの更新はプレイヤーの移動後に行い、地形にめり込まないよう持ち上げる。捕食時の揺れは小さくし、追従位置にノイズを蓄積させない。衝突の安全な細かい刻みは維持し、獲物AIとHUDは必要な頻度で更新する。
水中のモデル表面には、assets/shaders/marine-light.fragで時間変化する網目状の光の揺らぎ（コースティクス）を加える。遠くでは細い線をならして、ちらつきを抑える。
プレイ範囲の外側には、遠景の丘と湾を囲む岬（maps/coast.glb の CoastalHills）を置く。接触判定は持たない。海底は浅瀬から沖へ滑らかに深くなる。
水中では空と水面の霞の色をシーンのフォグ色に合わせ、遠くの地形が輪郭を残さず霞む。
海面は maps/coast.glb の形状に assets/shaders/water.vert と water.frag を適用する。波は岸へ向かう6本のうねりで、山が尖り谷が平らな形をしている（同じ式を `Water.ts` の surfaceHeight にも持ち、船やブイはその高さに浮く）。面の傾きは画素ごとに計算し、その上に風による細かいさざ波を重ねる。色は水深による光の吸収（浅瀬は青緑、深場は紺）、波の背を透ける緑の光、視線角度に応じた空と景色の映り込み、太陽の鋭い照り返しと広いきらめきで決まる。白波は高く急な波頭に筋状に出る。水中から見上げると、真上の円の中だけ空が明るく見え、その外側は海中を映す（スネルの窓）。水面のメッシュはカメラの真下が最も細かく（約1.5m刻み）、水平線へ向かって粗くなる板で、カメラに付いて動く。

## 確認
npm run test:smoke は起動済みの開発サーバー（5173）とWindows標準パスのChromeを使用し、方向・深さ・旋回・成長の捕食判定と高速衝突の回帰テスト、全GLBの読み込み・砂浜と海の必須パーツ・マップに小物が混入していないこと・3D描画・初回捕食・一時停止・潜水・マップモデル読み込み失敗時の開始抑止を確認する。別環境では smoke.cjs の executablePath を変更する。
連続したビーチの幅と接触判定、砂浜の小物の接地、詳細モデルのパーツ別判定、獲物が地形の上に出現することも確認する。`node scripts/preview-models.cjs` でモデル一覧のプレビュー画像を保存できる。
